# dsh-awesome-hud

为 DeepSeek Harness Web / 桌面端的聊天页加一块悬浮 HUD 面板：会话状态、上下文占用与一键压缩、Git 变更、子代理、任务与 MCP 启停，一屏看全。

> 点击会话页右上角的「HUD面板」开合面板。面板与官方右侧栏、[dsh-better-sidebar](https://github.com/omdsh-dev/DSH-better-sidebar) 右侧栏互斥协作：侧栏展开时面板临时让位，不遮挡也不额外挤压正文。

## ✨ 功能总览

| 模块 | 你能看到 / 能做什么 |
| --- | --- |
| 会话 | 工作区与会话名称、运行状态、模型与思考等级标签；菜单里重命名、置顶、分支、归档、复制。 |
| 上下文 | 占用率与进度条、会话统计与 Token 用量；一键压缩，或派子代理写交接文档。 |
| 用量 | DeepSeek 余额、OpenCode Go 额度、Codex 额度；折叠后在标题展示其中一项。 |
| 产物 | 本会话及其子会话写出的文档 / 表格 / 演示 / 图片，以及本会话交付的文件；点击预览，右键加入聊天或复制路径。 |
| Git | 分支与变更数量、暂存与未暂存分组、diff、commit（含 AI 生成提交信息）、git graph。 |
| 任务 | 会话任务清单与完成状态，随任务变化实时刷新。 |
| 子代理任务 | 当前会话的子代理层级与状态，点击在右侧栏打开该子代理会话。 |
| 计划清单 | plan 模式产出的计划与三种状态，点击查看计划全文。 |
| 便笺 | 按工作区共享的多条便笺，支持图片、拖动排序、导入与发送到聊天输入框。 |
| 待办 | 按工作区共享的待办清单，勾选、编辑、拖动排序、清空已完成。 |
| MCP | 已接入的 MCP 服务与全局启停开关。 |

面板另提供：**模块折叠与置顶**、**卡片 / 边栏两种面板样式**、**左 / 右两种展开位置**、**内置使用说明页与更新日志页**。

## 🧩 模块与页面

### 会话模块

显示工作区名称、会话名称、会话状态，以及合并成一个标签的模型名与思考等级（按等级着色）。两个名称都可以点击，在鼠标位置打开操作菜单：

- **工作区菜单**：重命名、在文件管理器中显示、复制路径；
- **会话菜单**：置顶 / 取消置顶、重命名、分支会话、复制会话 ID、复制会话名称、归档会话；
- **重命名**：名称原位变为输入框，Enter 保存、Esc 取消、点其他位置也会保存。

![会话模块](docs/module-session.png)

### 上下文模块

标题右侧是「当前占用 / 最大上下文（占用率）」，进度条用颜色表示占用率；底部两行分别是会话统计（轮数、步数、tok/s）与 Token 用量（总量、缓存命中）。鼠标悬浮在进度条上会切换成分段样式，分段表示 System prompt、Tool definitions 与 Messages；悬浮两行可看完整明细。

- **压缩**：会话空闲时可点，任务进行中置灰；
- **交接**：点「压缩」右侧的下拉菜单，子代理会把交接文档写进工作区的 `docs/handoff/` 目录，进度在「子代理任务」模块里可见。

![上下文模块](docs/module-context.png)

### 用量模块

- **DeepSeek 余额**：始终展示，没有数据时显示 `—`；
- **OpenCode 用量**：OpenCode Go 三个窗口的用量百分比；
- **Codex 额度**：已订阅时显示 5 小时与每周额度，未订阅时显示免费额度；
- **点击跳转**：点余额或百分比打开对应的设置页；
- **折叠后信息**：折叠后可在标题右侧展示余额或其中一项额度，展示内容随设置切换。

前三项由两个关联插件提供：[dsh-account-usage](https://github.com/Ycet/dsh-account-usage)（余额与 OpenCode 用量）、[dsh-codex-subscription](https://github.com/WSL043/dsh-codex-subscription)（Codex 额度）；未安装或未启用时对应行不展示，设置项置灰并给出原因。

![用量模块](docs/module-usage.png)

### 产物模块

列出本会话及其子会话（子代理）**用 `write` / `edit` 写出的**文档、表格、演示与图片，以及本会话用官方 `present` 交付的文件，按最后一次改动排序，最多 10 个文件，默认先显示 3 个、可展开查看全部；没有产物时模块整体不展示。只认这两类 durable 证据：重启 DSH 后列表仍能重建，也不会把同工作区其它会话、或你自己手改的文件算进来（终端命令直接生成的文件不再自动收录）。交付路径必须落在会话工作区内，工作区外的路径不列入，因为右侧栏预览按会话工作区解析。子代理的产物取它日志里的 `write` / `edit` 记录（fork 子代理只算它自己写出的部分，不重复父会话的历史），路径换算到主会话工作区，工作区之外的（例如 worktree 里的）不收录。**分支会话**继续显示分支之前的产物：DSH 不记录分支的来源，插件用「继承前缀里 `job` 事件的 `owner` + 边界事件时间」认出源会话，从而沿用它的子代理产物。

- **悬停路径**：鼠标在文件行上停留 0.5 秒显示完整相对路径；
- **点击打开**：在右侧栏打开文件内容；
- **右键菜单**：添加至聊天（以 `@` 引用加入聊天输入框）、在文件夹显示、复制文件名称 / 相对路径 / 绝对路径。

![产物模块](docs/module-outputs.png)

### Git 模块

标题右侧是当前分支与变更文件数量；变更文件分「已暂存」与「未暂存」两组，组名右侧是文件数量，支持列表与文件树两种查看方式，文件行最左是状态字母、随后是文件名与灰色相对目录，最右是 `+新增 / -删除` 行数。

- **分支按钮**：切换已有分支或新建分支并自动切换；
- **初始化仓库**：工作区不是仓库时按钮变成这一项，点击即可建仓，并同时写入 `.gitignore`；
- **悬停操作**：暂存区文件可移出暂存区，变更区文件可撤销或添加至暂存区（文件夹行对整棵子树批量执行）；
- **右键菜单**：暂存 / 撤销 / 加入仓库根的 `.gitignore`；
- **diff**：左键点击文件在右侧栏打开 diff；
- **revert**：撤销全部未暂存变更（未跟踪文件一并删除），操作前需要二次确认。

![Git 模块](docs/module-git.png)

#### graph 页面

点模块里的「git graph」打开提交列表，分页加载（每页最多 80 条，滚动到底部继续加载）；当前分支为蓝底白字，其他分支为灰底黑字。右键点击提交可复制短哈希 / 全哈希 / 提交标题，或从此处创建分支、合并至当前分支，以及 soft / mixed / hard reset。

![git graph 页面](docs/git-graph.png)

#### commit 页面

点「commit」提交暂存区；「AI generate」按提交规范生成提交信息，生成依据是「提示词 + 暂存区变更」，默认提示词里含日期与版本规范，可在弹窗顶部展开后修改并保存。没有暂存文件时按钮仍可打开弹窗，此时 commit 与 AI generate 置灰。

![commit 页面](docs/git-commit.png)

### 任务模块

显示会话的任务清单与完成状态，进行中的任务带旋转图标，已完成的任务收在列表下方、可展开查看；底部给出已完成、进行中与待处理的数量，任务变化时列表自动刷新。没有任务时模块不展示。

![任务模块](docs/module-tasks.png)

### 子代理任务模块

显示当前会话的全部子代理，按层级缩进，执行中为黄色、已完成为绿色；超过 3 个时先显示 3 个。点击条目在右侧栏打开该子代理会话，主会话保持打开。没有子代理时模块不展示。

![子代理任务模块](docs/module-subagents.png)

### 计划清单模块

显示 plan 模式产出的计划：待审批为黄色、已执行为绿色、已废弃为灰色并带删除线，底部是三种状态的数量，超过 3 个时先显示 3 个。点任意一行查看计划全文（按 Markdown 渲染）。

![计划清单模块](docs/module-plan-list.png)

![计划全文页面](docs/plan-content.png)

### 便笺模块

多条便笺按工作区共享（同一工作区目录下的会话共用同一组），每条单独保存标题与文字，字数不限、图片最多 20 张。

- **列表**：便笺条列表展示全部便笺，点击进入编辑，鼠标悬停显示删除按钮；
- **拖动排序**：按住便笺条左侧的拖动条调整顺序；
- **新建**：「添加便笺」新建空白便笺并进入编辑；「从聊天创建」用输入框的文字与图片新建便笺；
- **删除**：删除时按钮换成取消与确认，点确认才删除；「删除全部便笺」同样需要确认；
- **编辑视图**：默认在模块内展开，点返回按钮回到列表；可改标题（为空时自动编号）、粘贴图片并按缩略图拖动排序、拖动底部手柄调整高度（所有便笺共用同一高度）；
- **与聊天互通**：「从聊天导入」先清空便笺再写入输入框内容；「添加至聊天」先清空输入框再写入便笺内容（图片按便笺顺序加入）；「清空」需要二次确认；
- **弹窗编辑**：在设置里开启后，点便笺条在弹窗中编辑，模块保持列表视图。

![便笺模块](docs/module-notes_01.png)

![便笺编辑视图](docs/module-notes_02.png)

### 待办模块

按工作区共享的待办清单：勾选条目即标记完成、取消勾选即恢复；在输入框输入内容按 Enter 新增，点条目文字可编辑，删除时需要确认；拖动行左侧手柄调整顺序；「清空已完成」需要二次确认。标题显示已完成数量，已完成的待办收在下方、可展开查看。

![待办模块](docs/module-todo.png)

### MCP 模块

列出已接入的 MCP 服务与全局启停状态，点开关立即启停、不需要刷新页面；改动只影响目标服务，部分环境需要重启 DSH 后才生效。

![MCP 模块](docs/module-mcp.png)

## ⚙️ HUD 设置与面板行为

点会话模块右上角的齿轮打开设置，弹窗顶部是三个标签：**「HUD 设置」/「使用说明」/「更新日志」**（「使用说明」是内置上手指南，按模块分节、每节给小标题与逐条说明；「更新日志」按版本分组记录改动，左栏当前版本号右侧带「最新」标签）。

- **左栏**：勾选模块控制显隐、拖动手柄排序（从上到下就是面板顺序）、卡片的图钉可置顶该模块（同时只允许一个）；
- **右栏**：五张卡片——HUD 面板通用设置（面板样式：卡片 / 边栏，默认卡片；展开位置：左 / 右；两处默认开合）、上下文、用量、git 变更、便笺；
- **保存**：有改动时「保存设置」可点，关闭与 Esc 都不保存；左下角「恢复默认」在鼠标位置弹出重置选项；
- **置灰原因**：设置项不可用时置灰，说明文字用红色写明原因。

![HUD 设置弹窗](docs/hud-settings.png)

面板行为：

- **开合记忆**：开合状态按会话保存，新建会话页默认收起，默认值可在设置里修改；
- **折叠**：点模块标题折叠或展开，会话与上下文模块不能折叠，折叠状态按会话保存；
- **置顶**：置顶模块固定在「会话」下方，最高 40vh、超出在固定区内滚动、标题行照常吸附；
- **侧栏协作**：右侧栏展开期间面板临时隐藏，侧栏关闭后自动恢复。

## 🚀 快速开始

**方式一：从 npm 安装（推荐，支持插件页一键更新）**

```bash
# 1. 安装（无需 git；本机需有 pnpm，dsh plugin 会调用它）
dsh plugin --profile web add dsh-awesome-hud@0.21.5

# 2. 重启 DSH Web 服务并刷新页面
```

> [!NOTE]
> 从 npm 安装的副本可以在插件页直接升级：打开「插件 → 已安装」，有新版本时卡片显示「可更新」，详情页提供「更新到」。从 GitHub tag 或 Release 压缩包安装的副本不支持页内更新，需要先卸载再重新安装。

**方式二：从 GitHub 远程安装（tag 固定；无 npm 账号时可用，不支持页内一键更新）**

```bash
# 1. 安装（锁定版本 tag，要求本机 git 可访问 GitHub）
dsh plugin --profile web add "github:Ycet/dsh-awesome-hud#v0.21.5"

# 2. 重启 DSH Web 服务并刷新页面
```

**方式三：从本地源码安装（开发）**

```bash
# 1. 安装（将 <absolute-path-to-plugin> 替换为本地源码目录绝对路径）
dsh plugin --profile web add "dsh-awesome-hud@link:<absolute-path-to-plugin>"

# 2. 重启 DSH Web 服务并刷新页面
```

**方式四：从 Release 资产安装（tarball，无需 git、无需 npm 账号）**

```bash
# 1. 安装（可直接用 Release 资产 URL，也可先下载 .tgz 再传本地路径）
dsh plugin --profile web add "https://github.com/Ycet/dsh-awesome-hud/releases/download/v0.21.5/dsh-awesome-hud-0.21.5.tgz"

# 2. 重启 DSH Web 服务并刷新页面
```

安装完成后，聊天页右上角（「打开工作区」按钮左侧）出现「HUD面板」按钮，点击即可开合。**每个会话各自记住自己的开合状态**；新建会话页例外，每次进入都从收起状态开始，并在右上角提供独立的悬浮按钮。

### 桌面端安装（macOS）

先完全退出 DeepSeek Harness，再用桌面应用自带的 CLI 安装；不要用旧 Web CLI 管理 `desktop` profile：

```bash
# 从 npm 安装（推荐）
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop add dsh-awesome-hud@0.21.5

# 从本地源码安装（开发）
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop add "dsh-awesome-hud@link:<absolute-path-to-plugin>"
```

### 数据存放

便笺文字、待办、折叠、面板设置与开合记忆保存在当前浏览器或桌面应用的 `localStorage`；**便笺图片**以原图存在同一来源的 **IndexedDB**。安装插件不会自动搬运 Web 浏览器中的这些数据；模型与登录凭据由 DSH 管理。

## 🔧 技术栈

| 类别 | 内容 |
| --- | --- |
| Host 侧 | Node.js ESM、`ctx.webServer` 前缀路由、`ctx.settings`、`ctx.subagents` / `ctx.agents`、`ctx.commands`（压缩）、`ctx.subprocess`、`ctx.llm`（AI 生成提交信息） |

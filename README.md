## 🚀 快速开始

**方式一：从 npm 安装（推荐，支持插件页一键更新）**

```bash
# 1. 安装（无需 git；本机需有 pnpm，dsh plugin 会调用它）
dsh plugin --profile web add dsh-awesome-hud@0.19.1

# 2. 重启 DSH Web 服务并刷新页面
```

> [!NOTE]
> 从 npm 安装的副本可以在插件页直接升级：打开「插件 → 已安装」，有新版本时卡片显示「可更新」，详情页提供「更新到」。从 GitHub tag 或 Release 压缩包安装的副本不支持页内更新，需要先卸载再重新安装。

**方式二：从 GitHub 远程安装（tag 固定；无 npm 账号时可用，不支持页内一键更新）**

```bash
# 1. 安装（锁定版本 tag，要求本机 git 可访问 GitHub）
dsh plugin --profile web add "github:Ycet/dsh-awesome-hud#v0.19.1"

# 2. 重启 DSH Web 服务并刷新页面
```

**方式三：从本地源码安装（开发）**

```bash
# 1. 安装（将 <absolute-path-to-plugin> 替换为本地源码目录绝对路径）
dsh plugin --profile web add "dsh-awesome-hud@link:<absolute-path-to-plugin>"

# 2. 重启 DSH Web 服务并刷新页面
```

**方式四：从 Release 资产安装（tarball，无需 git、无需 npm 账号）**

```bash
# 1. 安装（可直接用 Release 资产 URL，也可先下载 .tgz 再传本地路径）
dsh plugin --profile web add "https://github.com/Ycet/dsh-awesome-hud/releases/download/v0.19.1/dsh-awesome-hud-0.19.1.tgz"

# 2. 重启 DSH Web 服务并刷新页面
```

安装完成后，聊天页右上角（「打开工作区」按钮左侧）出现「HUD面板」按钮，点击即可开合。

> [!NOTE]
> HUD 面板默认展开；**每个会话各自记住自己的开合状态**（按会话 id 存于 localStorage），在 A 会话收起不会影响 B 会话。**新建会话页（尚未开始的空白会话）例外**：该页每次进入都从收起状态开始（只改内存态、不写 localStorage，因此不影响任何会话的记忆），并在右上角提供独立的悬浮「HUD面板」按钮用于在该页展开（图片**大图预览**打开期间该按钮隐藏，避免浮在大图与预览关闭按钮之上）。模块可见性保存于 DSH profile 设置中，跨浏览器/设备随 profile 同步。

### 桌面端安装（macOS）

当前版本：**0.19.1**。先完全退出 DeepSeek Harness，再使用桌面应用自带的 CLI 安装；不要用旧 Web CLI 管理 `desktop` profile。优先从 npm 安装（可在插件页一键更新），本地开发时再改用源码目录：

```bash
# 从 npm 安装（推荐）
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop add dsh-awesome-hud@0.19.1

# 从本地源码安装（开发）
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop add "dsh-awesome-hud@link:<absolute-path-to-plugin>"
```

重新打开应用后，在会话右上角点击「HUD面板」。Codex 额度需要另行安装并登录支持当前 DSH 版本的 `dsh-codex-subscription`；DeepSeek 余额优先来自 `dsh-account-usage`，未安装/未启用时回退 DSH 官方账户服务（需登录 DeepSeek 账号）；OpenCode Go 用量与设置页页签来自 `dsh-account-usage`。

> [!NOTE]
> 便笺文字、待办、折叠、面板设置和面板开合记忆保存在当前浏览器或桌面应用的 `localStorage`；**便笺图片**以原图存在同一来源的 **IndexedDB**（同样随重启保留、按工作区共享）。安装插件不会自动搬运 Web 浏览器中的这些数据；模型与登录凭据由 DSH 管理。

## 🧭 使用说明

- **HUD 面板**：宽度 300px，高度上限为输入框底部（留 8px 底距），内容超出时面板内部滚动（**不展示滚动条**）。面板为**常驻固定展示**（正文与输入框按侧位让位）。展开位置由「HUD面板通用设置 → HUD 面板展开位置」决定：**右侧**（默认）贴在窗口右侧，聊天内容与输入框自动向左让位；**左侧**时贴在会话区左缘（会话列表右侧，8px 间距），正文与输入框向右让位；两种侧位下页面滚动条都停在窗口最右缘，会话页右缘的「轮次导航」指示条仍停在正文右缘，面板都不会与正文重叠。右侧栏展开期间面板隐藏且不推挤正文，关闭后恢复。
- **设置弹窗**：「会话」模块右上角齿轮打开设置弹窗，顶部是**「HUD 设置」/「使用说明」两个标签**（选中项带品牌色下划线，可随时切换）；设置页为**左右分栏**：中间一条分割线，左栏是模块启停与排序，右栏是模块的具体设置。
  - **左栏**：勾选控制「上下文 / 用量 / git / 子代理任务 / 任务 / 计划清单 / MCP / 便笺 / 待办」的显隐（「会话」模块恒展示），每张卡片左侧有**拖动排序手柄**（按住拖动调整该模块在 HUD 面板中的顺序，全局生效；拖动时其余卡片实时让位预览，松手才落盘）。左栏不随右栏滚动；弹窗高度随窗口自适应并压缩卡片间距，保证 9 张模块卡片始终全部露出。**新建会话页不渲染的模块（上下文 / 子代理任务 / 任务 / 计划清单）在该页的设置里按真实状态展示、置灰不可点击**（悬浮显示原因），其开关请在会话页调整。
  - **右栏**：三个**卡片式分区**（内容过多时只滚动这一栏）。① **「HUD面板通用设置」**：HUD 面板展开位置（左侧 / 右侧）、新建会话页默认展示、聊天会话页默认展示（后两项只影响还没有开合记忆的页面/会话）。② **「「上下文」模块设置」**：始终显示分段进度条（默认关闭，关闭时只在悬浮进度条时显示分段）、显示「会话统计」、显示「Token 用量」、**上下文模块位置固定**（默认关闭；开启后 HUD 面板上下滚动时该模块与会话模块一样停住，仅当上下文排在模块排序首位时可开启，否则置灰并说明原因）。③ **「「用量」模块设置」**：DeepSeek 余额、OpenCode Go 用量、codex额度三行恒列出，未安装或未配置/未登录的项置灰并给出行内原因（DeepSeek 走内置官方余额源，恒可切换），另有**展示「跳转」按钮**开关（默认启用，关闭后「用量」模块不再渲染该按钮及其菜单）。
  - **控件与页脚**：右栏启停项使用 DSH 官方 `Switch` 样式（`@deepseek-ai/dsh-client-ui-primitives`，不可用时回退等价本地样式），「左侧/右侧」使用官方分段控件。底部左侧的**「恢复默认」**在当前设置与默认不同时激活，可把勾选、用量行、上下文设置、面板设置与排序一并恢复默认（仍需点「确认」落盘）。弹窗支持点击遮罩、右上角「关闭」、「取消」或 `Esc` 关闭（关闭等同取消，不保存改动）；确认后写入并关闭。打开时焦点进入弹窗，Tab 在弹窗内循环，关闭后回到齿轮按钮。

- **git 模块**：常驻展示——新建会话页与会话页都默认展示，工作区不是 git 仓库时也展示（标题栏右侧提供「初始化仓库」按钮，位置与分支按钮相同；点击后在该工作区执行 `git init`，成功后模块切换为仓库态：按钮变为分支按钮，正文出现动作区与变更统计，并由随后的轮询保持刷新；已是仓库时该按钮不出现）。每 5 秒随面板打开自动刷新（写操作后立即刷新）；标题栏右侧分支按钮点击弹出下拉列表——可切换已有分支（当前分支高亮带勾标记；点击当前分支会提示「当前已在分支」而非静默关闭），或在输入框中输入新分支名点击「添加」创建并自动切换；「git graph」弹窗按每页最多 80 条分页展示当前仓库（全部引用）提交图（滑到列表底部出现「加载更多」按钮点击追加下一页，全部加载完后底部显示「已显示全部提交」提示）；分支标签中，当前分支为蓝底白字，其他分支为灰底黑字；HEAD 指向版本以放大的白色填充圆点 + 蓝色描边标记。提交行右键菜单可复制短哈希（前 7 位）/全哈希（40 位）/提交标题，并提供以下受保护操作：
  - **从此处创建分支**：点击后**原菜单项位置**展开为输入框 + 「取消」/「确认」图标按钮（输入框为空时确认按钮置灰）。输入合法分支名并点击确认后，以该提交为起点执行 `git checkout -b <名称> <提交>` 并切换到新分支：成功提示后菜单关闭、git 快照与提交图刷新，新分支标签随即显示为蓝底当前分支。分支名重复、或本地修改会阻止切换时给出提示（后者列出受影响文件）并**保留输入内容**，便于改名重试；不自动 stash、不强制切换。输入框内按 Enter 不触发创建，按 Escape 取消输入并恢复为原菜单项（再按一次关闭菜单）；Git 操作（merge / rebase / cherry-pick / revert）进行中时该项置灰。
  - **合并至当前分支**：先在原菜单项位置显示行内「确认？/取消」，确认后执行 `git merge --no-edit`；已包含提示「无需合并」、本地修改阻塞提示受影响文件、合并冲突自动 `git merge --abort` 回滚并列出冲突文件清单。
  - **reset(soft)-保留暂存**：仅可选择当前本地分支历史中、早于 HEAD 的提交；二次确认后以 `git reset --soft` 回退，所选提交之后的提交内容保留在暂存区。
  - **reset(mix)-取消暂存**：同样仅可回退至当前本地分支历史中的较早提交；二次确认后以 `git reset --mixed` 回退，所选提交之后的提交内容保留在工作区且不在暂存区。
  - **reset(hard)-撤回更改**：二次确认后以 `git reset --hard` 回退并丢弃所选提交之后的提交内容，以及已跟踪文件的未提交修改；未跟踪文件不会被删除。
  - reset 在未检出本地分支、Git 操作进行中、所选提交不在当前分支历史中或所选提交即为 HEAD 时不可用。变更文件按分组展示（状态字母按类型着色——修改 `M` 黄色、新增 `A` 蓝色、删除 `D` 红色、未跟踪 `?` 灰色，重命名 `R` / 复制 `C` 蓝色）：
  - **分组**：staged（暂存区）与 changes（未暂存区，含未跟踪）两组，组名右侧灰色数字为组内文件数，并提供一键按钮：changes 组「+」暂存全部未暂存文件、staged 组「-」取消暂存全部暂存文件；某组无文件时该组不展示
  - **文件行操作**：**左键**点击任一文件行在右侧栏打开该文件的 diff（优先官方「第 N 轮改动」review 页；该文件不在最新一轮、官方 review 不可用或右侧栏缺失时回退 better-sidebar 的工作树 diff tab）；**右键**（或键盘 Shift+F10 / 菜单键）弹出选项菜单——staged 组文件提供「remove from stage」（移出暂存区）；changes 组文件提供「add to stage」（暂存该文件）与「revert」（撤销该文件变更；未跟踪新建文件与 intent-to-add 预登记文件撤销 = 删除该文件，均带二次确认与受影响文件清单）。文件行悬停 0.5 秒后在鼠标位置显示完整路径提示
  - **commit**：按钮在暂存区无文件时置灰；点击弹出提交弹窗（展示待提交暂存文件数量 + 多行输入框 + AI generate + commit），输入为空时 commit 置灰；Enter 仅换行，需点击 commit 才会提交；提交范围仅为暂存区
  - **AI generate**：固定调用 DeepSeek 官方 DeepSeek Flash 系列模型（`deepseek-account` 路由的 `deepseek-flash`，`reasoningEffort: low`），不再使用当前会话所选模型；首次点击只进入「确认？」并在按钮左侧显示说明，第二次点击才生成（3 秒内未确认自动复位，点击按钮外或按 Escape 取消），生成时按钮禁用。生成时结合暂存区全部 diff（超 16KB 截断）与当前会话最近对话上下文（用户直接消息与助手消息，供理解改动意图；若对话中用户明确指定了提交备注则直接采用），按内置本地 git 提交规范生成提交信息并填入输入框——格式 [YYMMDD] 开发项目名称 vX.Y.Z：修改内容（日期取系统当前时间；版本号依规范自动判断：破坏性变更→主版本、向后兼容新功能→次版本、修复/文档→修订号；项目名与当前版本取自工作区向上最近的 package.json）；生成后自动校验版本号是否已按规范递增，不达标时自动重试一次（附上一次输出与原因反馈），仍不达标则照常填入并提示核对
  - **revert**：按钮在无任何未暂存变更（含未跟踪）时置灰；点击后二次确认弹窗列出全部受影响文件（未跟踪文件带 `?` 前缀标识），确认后还原已跟踪文件的未暂存变更并删除未跟踪新建文件与 intent-to-add 预登记文件；确认框与 staged 组会明确提示「暂存区文件不会被撤销」（如有需要请先移除暂存）；若存在无法删除的目录条目（嵌套仓库/子模块），会明确提示并跳过，不再静默当作成功

  - **已执行**（绿色标签）：用户在计划审查中审批通过（`exit_plan_mode` 返回批准结论），进入执行阶段；后续退出 plan 模式不会改为废弃。此标签不代表所有步骤已经完成；
  - **已废弃**（灰色标签、文字划线变淡）：审查未通过——包括拒审/要求修改/打断审查（错误结果）、在计划审查卡片上点「要求修改」（关闭审查、回到输入框；DSH 0.2.1-rc.5 起该操作以**成功结果** `{ approved: false }` 返回且计划模式仍生效，HUD 立即判为已废弃），以及计划无审批结论但 plan 模式随后退出（如 `/plan off`）。兼容新版消息级错误标记、旧结果块、结果文案与 plan 模式退出信号；
  - 行主文字取计划首个 Markdown 标题，无标题时截取正文；点击任一行弹出计划全文弹窗（标题、状态、产出时间与正文，正文按轻量 Markdown 渲染，支持标题/列表/代码块/链接/引用与 GFM 表格）；模块底部展示「x 已执行 · x 待审批 · x 已废弃」三态计数（含 0 恒显）；模块可折叠，默认展开。
- **MCP 模块**：开关控制 dsh 全局的 MCP 服务启停——经 DSH 官方插件管理器 `pluginManager.setPluginEnabled` 按行写入 profile `cordis.patch.yml` 并等待热重载完成，开关即时生效、无需刷新页面，只改目标服务、不改动其它插件配置；未启用 HMR 的 profile 会提示「重启后生效」；模块默认展开，无任何 MCP 服务时仍展示空状态。
- **便笺模块**：按**工作区共享**的便笺——以会话所在工作区目录为键保存（同一工作区目录下的所有会话共用一份内容与图片，含输入框高度），文字存 `localStorage`、图片以原图存 IndexedDB，重启 DSH 后依旧存在；删除或归档其中任一/全部会话都不影响该工作区其它会话的内容，下次在同一工作区新建会话时内容与图片依旧存在。输入框底部拖拽手柄可拖拽调整高度（实时持久化）；**不限制字数**，底部也不再显示字数与图片张数。**图片**：直接在输入框里粘贴（`image/*`，最多 20 张；字节上限沿用宿主的会话内附件校验），缩略图在输入框上方横向滚动，点击看大图（Esc / 遮罩 / 关闭按钮退出），鼠标悬浮缩略图右上角出现移除按钮（触屏常显）；「清空」或移除都会释放对应原图。**从聊天导入**（位于「添加至聊天」左侧）：先清空便笺里的文字与图片（旧原图一并释放并删除 IndexedDB 记录），再写入当前会话/新建会话页输入框里的文字与图片，便笺非空时先弹确认，非图片附件会跳过并提示；输入框内容不清除，输入框为空时按钮置灰、只提示且不清空便笺。**添加至聊天**：先清空会话输入框里的文字与图片（逐个移除并释放旧附件），再写入便笺文字并按便笺顺序加入图片；输入框非空时先确认，为空则直接写入，成功后焦点回到输入框；便笺内容保留；清空后写入失败不回滚（保持已清空 + 已写入部分并提示）。有文字或图片时「清空」可用：首次点击进入红色确认态，二次点击后同时清掉文字与图片（点击其他区域、Escape 或 2 秒超时会取消）。模块可折叠/展开（状态持久化）。未归属工作区（无 cwd）的会话降级为会话级隔离，不与其它会话共享。
- **待办模块**：按**工作区共享**的待办清单——以会话所在工作区目录为键保存（同一工作区目录下的所有会话共用同一份清单与顺序，本地持久化）；每条待办为**卡片式**（1px 描边 + 浅底 + 10px 圆角，与「HUD 设置」里的模块卡片同款，行距 6px），**编辑 / 删除按钮默认隐藏，鼠标悬浮该行时才出现，键盘聚焦（`:focus-visible`）也会显示**（两者改为**绝对定位浮层**：文字独占整行宽度，悬浮时浮层以行底色实底铺在行右端、左侧 16px 渐隐把文字淡出，既不会被挤窄、也不会重新换行；触屏等无 hover 环境按钮常显并给文字留出右侧避让；鼠标拖动后不会再滞留）；勾选完成/恢复、添加/删除项、整行拖拽排序（拖动手柄位于行最左侧勾选框之前，**手柄热区覆盖整行高度**，多行条目也能整列拖起；拖动时其余条目按真实行高实时让位，松手才保存顺序）、一键清空已完成（二次确认弹窗，无已完成项时按钮置灰）；底部展示完成计数；模块可折叠/展开（状态持久化）。同一工作区多会话/多标签页同时编辑时按条目 id 归并，不会互相清空。
- **折叠状态**：各模块折叠/展开状态刷新页面后保持（localStorage）；「会话」模块图标使用 DSH favicon。
- **新建会话页**：右上角提供独立悬浮「HUD面板」按钮（该页没有会话页眉；Windows 普通窗口中入口位于原生标题栏下方，全屏时取消该偏移）。该入口与聊天会话页保持同一顺序：始终排在右侧工具按钮簇左侧（装有 better-sidebar 时，其「底部面板」切换按钮排在入口右侧、两个页面的间距一致）——这让两个页面的入口位置看起来完全相同。**图片大图预览打开时该按钮隐藏**——预览是铺满视口的模态浮层（`role="dialog"` + `aria-modal`，如 `dsh-codex-subscription` 的图片查看器），而 HUD 入口的层级远高于它，不隐藏就会浮在大图与右上角预览关闭按钮之上；预览关闭后按钮自动恢复，面板开合状态不受影响（判定只看浮层语义与视口覆盖率，不绑定第三方类名）。该页每次进入都从收起状态开始，点击按钮后展开；面板固定贴右侧、宽 300px，输入框与正文左移让位，按钮保持原位。官方右侧栏（含 better-sidebar）展开期间，该悬浮入口与面板一并隐藏——入口不再移到侧栏左侧，也不再把展开态面板的位置写进定位；关闭侧栏后入口**立即出现在打开侧栏前的位置**，不会先闪到侧栏边缘，并回到该页此前的开合状态（除非已手动收起 HUD）。新建页的 Git、便笺、待办和便笺发送目标使用同一最近工作区；MCP 作为全局模块独立刷新，无会话或工作区时也可查看和启停。该页展示会话 / 用量 / git / 便笺 / 待办 / MCP 模块（git 常驻，目标工作区不是仓库时提供「初始化仓库」；「用量」模块恒定展示，DeepSeek 余额无数据时显示 `—`）；尚无会话记录时不展示会话标题与状态徽标（工作区标题菜单照常可用）。进入真实会话后加载该会话自己的开合记忆，标题栏原按钮接管入口。

## ⬆️ 升级说明（v0.11.x → v0.19.1）

「便笺」「待办」由**会话级**改为**工作区级**。升级后首次在某工作区打开面板时，插件会做一次性的自动归并迁移：

- 便笺：取该工作区内候选会话中 `updatedAt` 最新的一份；
- 待办：按条目 id 去重合并（同 id 以先出现的为准），顺序保持稳定；
- 迁移结果写入工作区键，并记录迁移标记（`dsh-awesome-hud:workspace-migrated`），同一工作区只迁移一次；
- **旧的会话级键保留不删除**，回滚到旧版本后仍可读到迁移前数据。

如介意旧键占用的空间，可在确认迁移完成后于浏览器控制台执行 `localStorage.removeItem("dsh-awesome-hud:workspace-migrated")`，再删除 `dsh-awesome-hud:notes` / `dsh-awesome-hud:todos` 中「非工作区路径」的旧键（删除后无法再回滚迁移）。

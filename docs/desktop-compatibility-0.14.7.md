## 修复内容

| 问题 | 修复 |
| --- | --- |
| 桌面子代理导航接口与旧 Web 接口不同 | 优先调用 `uiWorkspace.openSession`，保留旧接口兜底，并报告导航失败 |
| 账户菜单中的设置按钮带隐藏快捷键，且菜单延迟出现 | 忽略隐藏快捷键文本，等待菜单和设置页面出现；区分自制「账户」、官方「账号与余额」和「Codex 订阅」入口 |
| 模型快照发生变化后信息可能滞后 | 订阅当前快照 store，并处理订阅切换和取消订阅 |

| OpenCode 跳转依赖个人目录 | 改用通用控制台地址 |
| Git 合并冲突主要出现在 stdout，原逻辑可能漏检 | 同时检查 stdout / stderr；冲突后验证 abort 结果，回滚失败时明确报错 |
| 空 MCP patch 为 `[]` 时追加配置产生非法结构 | 追加前移除空列表占位，保留用户注释与其他内容 |

## 复验方法

从插件目录运行普通测试：

```bash
npm test
```

普通测试会跳过一项需要桌面发行包的 subprocess 集成测试。为完整复验，将已安装桌面发行包中的 DSH runtime 解包到可读取目录，并设置 `DSH_TEST_INSTALL_ROOT`；该目录需包含 `node_modules/@deepseek-ai/cordis` 和 `node_modules/@deepseek-ai/dsh-subprocess-local`：

```bash
DSH_TEST_INSTALL_ROOT="<path-to-extracted-desktop-dsh-runtime>" node --test test/*.test.mjs
```

新增的 `desktop-compat.test.mjs` 验证客户端接口和延迟菜单行为；`desktop-host.test.mjs` 使用真实桌面 subprocess provider，但会话、设置、loader、命令、子代理和模型服务使用夹具。所有 Git 写操作和 MCP 配置写入均限定在自动创建并清理的临时目录内。

本次确认的实际环境为 macOS 桌面 `0.2.0-rc.2`。Windows、Linux、其他 DSH 版本，以及上表中没有真实数据的场景，需要在对应环境复验。升级 DSH 后尤其应复查设置菜单、子代理导航、输入框绑定及 MCP loader 接口。
